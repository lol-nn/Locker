# Locker
AINLOCKER — безопасная визуальная симуляция

Это шуточная визуальная программа на Python: вращающийся ASCII-череп, мерцание, терминальные эффекты и демонстрационный экран.

**Программа не шифрует, не удаляет и не блокирует файлы или Windows.**

## Запуск

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Установите зависимость:

```bash
python -m pip install -r requirements.txt
```

4. Запустите:

```bash
python main.py
```

## Управление

- `ESC` — закрыть симуляцию.
- `F11` — переключить полноэкранный режим.

Окно можно закрыть обычным крестиком. Таймер и системные сообщения являются только визуальными элементами.
